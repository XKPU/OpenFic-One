# Changelog

## [0.2.0] - 2026-11-28

### Added

- 内置 proot 与精简 Ubuntu 24.04 (arm64) 根文件系统，无需 root 即可在应用私有目录运行完整 Python 运行时。\
  Built-in proot and a minimal Ubuntu 24.04 (arm64) root filesystem, allowing a full Python runtime inside the app's private directory without root.
- 启动即进入控制台页面，可切换应用主题及语言。\
  Launches directly into the console page, where the app theme and language can be switched.
- 在首次启动以及更新 OpenFic 版本时，可以选择使用的镜像。\
  Mirrors can be selected on first launch and when updating OpenFic.
- 首次启动自动创建 `/opt/venv`，从所选 PyPI 镜像安装最新版 OpenFic，随后在本机 `127.0.0.1:8000` 启动服务并使用 WebView 展示界面。\
  On first launch, automatically creates `/opt/venv`, installs the latest OpenFic from the selected PyPI mirror, then starts the service on `127.0.0.1:8000` and displays the UI in a WebView.
- **更新检查**：每次启动先向 PyPI 查询最新 OpenFic 版本、向配置的 OpenFic One 更新源查询最新 OpenFic One 壳版本。\
  **Update check**: On every launch, queries PyPI for the latest OpenFic version and the configured OpenFic One update source for the latest OpenFic One shell version.
- **「One 设置」入口**：在设置分类列表末尾插入「One 设置」项。可查看启动器与 OpenFic 版本、检查两者更新、控制更新频率、导入/导出备份数据（与桌面端通用）。\
  **"One Settings" entry**: Adds a "One Settings" item at the end of the settings category list. It shows the launcher and OpenFic versions, checks both for updates, controls update frequency, and imports/exports backup data (compatible with the desktop version).
- OpenFic One 界面语言及主题始终与 OpenFic 同步。\
  The OpenFic One UI language and theme always stay in sync with OpenFic.
- OpeFic、OpenFic One、本地嵌入/重排序模型更新/下载源按界面语言排序：中文界面优先国内镜像，英文界面优先官方源。\
  Update/download sources for OpenFic, OpenFic One and local embedding/reranking models are ordered by UI language: Chinese prefers domestic mirrors, English prefers official sources.
- 通知设置页新增「应用启动管理」入口及「前往」按钮，跳转应用启动管理页面。\
  Adds an "App startup management" entry and a "Go" button to the notification settings page, opening the app startup management page.

### Fixed

- 注入脚本 URL 追加内容哈希 `?v=<md5>`，注入标记按脚本内容 CRC32 判定；覆盖安装即可绕过 OpenFic 前端的 cache-first Service Worker。\
  Injected script URLs include a content hash (`?v=<md5>`) and the injection marker is determined by the script's CRC32; an overlay install bypasses OpenFic's cache-first Service Worker.
- 系统通知兼容层 `ofone-notify.js`：向 WebView 注入 `Notification`（`permission`、`requestPermission`、构造函数），实际通知由原生 `NotificationManager` 发出，并适配 Android 13+ `POST_NOTIFICATIONS` 运行时授权。\
  System notification compatibility layer `ofone-notify.js`: injects a `Notification` shim (`permission`, `requestPermission`, constructor) into the WebView, with real notifications sent by native `NotificationManager` and Android 13+ `POST_NOTIFICATIONS` runtime permission handling.
- 侧边栏 logo 与字标空白：上游前端用无前缀 `mask:url(...)` 引用图标，旧版 Android WebView 不支持。\
  Blank sidebar logo and wordmark: the upstream frontend references icons with unprefixed `mask:url(...)`, which older Android WebViews do not support.
- 返回手势与硬件返回失效：对 OpenFic WebView 注入返回路由。\
  Back gesture and hardware back not working: injects a back route into the OpenFic WebView.
- 修复索引因 Android SELinux 禁止硬链接而报 `Permission denied`：proot 增加 `--link2symlink`，绕开 LanceDB 提交时用 `linkat` 创建 `_versions` 失败的问题。\
  Fixed indexing failing with `Permission denied` because Android SELinux forbids hardlinks: proot now uses `--link2symlink` to bypass LanceDB's failed `linkat` call when creating `_versions`.
