# v0.1.13

日期：2026-11-27

## 修复：底部覆盖层 / 下拉菜单点击穿透

- 修复在「One 设置」中底部上滑覆盖层（更新检查、导入、导出、暂停天数输入等）与下拉菜单可见但点不到、点击直接穿透到下方设置页的问题。
- 根因：OpenFic 设置使用 Radix 模态对话框，打开时会把 body 设为 pointer-events:none（可继承）。覆盖层和下拉菜单此前挂载在 document.body，继承 none 导致点击穿透；即使点击到达，也会被对话框的「外部点击」逻辑判定为点到外面而关闭整个设置。
- 修复方式：把覆盖层与下拉菜单挂载进设置对话框内容子树（优先 .settings-dialog-main），既不受 pointer-events:none 影响而可正常点击，也不会被当作外部点击关闭对话框；position:fixed 仍相对视口（祖先无 transform），定位不变。
- 新增内部辅助函数 overlayHost() 统一决定挂载点。

## 说明

- 本次为覆盖安装（adb install -r），不卸载、不丢失 rootfs 与用户数据。
