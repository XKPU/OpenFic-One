# Changelog

## [0.1.6] - 2026-11-27

### Changed

- 「One 设置」面板按 OpenFic 原生设置对话框重做：复用其侧栏 / 内容区 / 底部保存栏结构与 CSS 变量，桌面端显示左侧栏、窄屏自适应，亮暗主题自动跟随页面。\
  The One settings panel is rebuilt on OpenFic's native settings dialog: it reuses the sidebar / content / save-bar structure and CSS variables, shows a sidebar on desktop, adapts to narrow screens, and follows the page's light/dark theme automatically.
- 界面语言与界面主题改用原生风格下拉，自动更新等开关改用原生风格拨动开关。\
  Language and theme now use native-style dropdowns; auto-update toggles use native-style switches.
- 更新 OpenFic 时改为通过 `pip install --upgrade` 原地升级，保留现有环境与用户数据，无需再重建 Python 环境，耗时从数分钟降到数十秒。首次安装仍走完整流程。\
  Updating OpenFic now upgrades in place via `pip install --upgrade`, keeping the existing environment and user data; no Python rebuild is needed and the wait drops from minutes to roughly half a minute. First-time install still runs the full flow.
