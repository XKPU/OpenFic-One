# Changelog

## [0.1.5] - 2026-11-27

### Added

- 控制台标题栏新增「界面主题」入口，支持跟随系统 / 浅色 / 深色，并同步写入 OpenFic 的 `theme` 设置，控制台与 OpenFic 页面主题保持一致。\
  The console header gains a UI theme switch (follow system / light / dark); the choice is written to OpenFic's `theme` setting so the console and the OpenFic pages share one theme.
- 「One 设置」面板新增主题选择，面板配色改为 CSS 变量并按主题切换深浅两套取值。\
  The One settings panel gains the same theme switch; its colors are now CSS variables with separate light and dark values.

### Changed

- 控制台、更新面板、镜像面板、应用更新下载面板的配色统一由 `Palette` 提供，替换原先散落的硬编码色值，跟随 OpenFic 的 Radix 色板。\
  Colors of the console, update panel, mirror panel and app download panel now come from `Palette`, following OpenFic's Radix palette instead of scattered hard-coded values.

### Fixed

- 返回键在 OpenFic 首页不再直接退出应用，改为回到后台，保留本地服务与页面状态。\
  Back on OpenFic's home page no longer exits the app; it moves the task to the background and keeps the local service and page state.
