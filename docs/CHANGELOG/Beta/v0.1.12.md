# v0.1.12

日期：2026-11-27

## 新增：通知设置页「应用启动管理」入口

- 在 OpenFic 的通知设置页新增一行「应用启动管理」，说明为「若您希望让 OpenFic 长期在后台运行，请在应用启动管理中将 OF-One 设置为手动管理，并允许后台活动。」
- 右侧提供「前往」按钮，点击直接跳转系统设置中的应用启动/电池优化页面（优先请求忽略电池优化，其次应用详情页，最后系统设置）。
- 该行复用原生 Radix 组件类名（`rt-Flex`、`rt-Text`、`rt-BaseButton` 等），字体、间距、按钮外观与原生的通知开关行完全一致；中英文随界面语言切换。

## 说明：无需 ADB 也可忽略旧缓存

- 注入脚本 URL 已带内容哈希（`?v=<md5>`），脚本内容一变 URL 即变，天然绕过 OpenFic 前端的 Service Worker 缓存（cache-first）。因此不依赖 ADB 清缓存，正常覆盖安装即可让新脚本生效。

## 说明

- 本次为覆盖安装（`adb install -r`），不卸载、不丢失 rootfs 与用户数据。
