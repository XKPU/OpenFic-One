# Changelog

## [0.1.7] - 2026-11-27

### Fixed

- 修复「更新 OpenFic」每次都从创建 Python 环境开始、无法原地升级的问题。原因：`/opt/venv/bin/python3` 是指向 `/usr/bin/python3.x` 的软链，宿主侧 `File.exists()` 会把绝对目标解析到宿主根，判定恒为首次安装。改用 `/opt/venv/pyvenv.cfg` / `/opt/venv/.ok` 这类常规标记文件判断是否已安装。\
  Fixed "update OpenFic" always starting over from creating the Python environment instead of upgrading in place. Cause: `/opt/venv/bin/python3` is a symlink to `/usr/bin/python3.x`, so the host-side `File.exists()` resolved the absolute target against the host root and always reported a fresh install. It now checks regular markers such as `/opt/venv/pyvenv.cfg` / `/opt/venv/.ok`.
