# v0.1.11

日期：2026-11-27

## 新增与重做：「One 设置」按原生设置风格重做

- **改为分级子页面**：从设置列表点「One 设置」进入独立子页面，与其它设置分类一样是「进入下一页」而非模态弹窗；一级设置页留在 DOM 中，从二级页返回时保留一级页面的滚动位置。
- **折叠分组**：按「启动器版本」「OpenFic 版本」「备份与数据」「通用」分组，每组标题显示当前版本号并带折叠箭头，默认折叠，点击展开。
- **原生外观**：全部复用 OpenFic 原生 Radix 组件类名（`rt-BaseButton`、`rt-SwitchRoot`/`rt-SwitchThumb`、`rt-SelectTrigger`、`rt-TextFieldRoot`、`rt-Text` 及 `rt-r-*` 间距/字号工具类），字体、图标与文字间距、开关/下拉外观与原生设置一致；子页面同原生详情页一样无额外转场动画。
- **更新检查频率**：每个版本区「更新检查频率」下拉，含「每次启动时更新 / 暂停更新 / 在指定天数内暂停更新」；选择「在指定天数内暂停更新」时从页面底部向上滑出覆盖层输入天数（点击空白不关闭）。
- **立即检查更新**：整行可点击，从页面底部上滑覆盖层（点空白不关闭），先显示转圈，再对比最新版本与当前版本：
  - 启动器区：有新版时展示更新说明，按钮文本为上游返回的下载源名称，点击开始下载并实时显示进度，完成后自动进入安装；取消则中止下载并清理已下载缓存。
  - OpenFic 区：有新版时显示「返回」「前往更新」两个按钮；无新版则显示确认按钮。

## 变更：数据导入导出

- 导出改为底部上滑覆盖层选择压缩格式（zip / tar.gz / tgz），导出对应格式的备份文件。
- 导入改为底部上滑覆盖层：选择备份文件（zip / tar.gz / tgz）后先在覆盖层显示文件名，点确认才开始导入。
- 仅支持标准库原生支持的 zip / tar.gz / tgz，不含加密压缩包（以保持可维护性）。

## 说明

- 本次为覆盖安装（`adb install -r`），不卸载、不丢失 rootfs 与用户数据。
