# v0.1.15（2026-11-28）

## 修复
- 导入备份「假重启」：导入前用 fork 方式读取 `/proc/<pid>/cmdline`，修正 `Util.readAll` 依赖 `File.length()` 导致 procfs（length 恒为 0）读空、孤儿服务进程无法被识别并杀死的 bug；导入改为无条件 `stopServer()`（含 `killOrphanServer`）后解压，导入完成再真正重启服务。真机实测导入后服务进程 PID 全部更换、端口重新监听、页面自动重载。
- 索引报错：proot 增加 `--link2symlink`，绕开 Android SELinux 禁止 app 域硬链接（LanceDB commit 用 `linkat` 建 `_versions` 失败 EACCES）。索引不再因 Permission denied 中止。（远程 embedding 模型下线 410 属外部问题，需用户更换模型。）
- 编辑器内进入 AI 页后按返回误退首页：`window.__ofoneBack` 检测 `.ai-sidebar-header` 并点击其中的「关闭」，正确收起 AI 面板回到编辑页。
- 通知设置页「前往应用启动管理」无法唤起设置：改用 Honor（`com.hihonor.systemmanager`）/华为（`com.huawei.systemmanager`）专用启动管理 Activity 与 action，最后回落系统设置。
- One 设置界面与原生不一致：页面顶部改为原生 `settings-dialog-mobile-topbar`（返回箭头+标题+关闭 X），折叠分组标题字号对齐原生字段标签。

## 变更
- 导出备份排除 `runtime`（Python 运行时，约 1.3GB），备份体积大幅缩小；导入时从旧目录恢复 `runtime`，服务可正常启动。
- 归档支持 zip / tar.gz / tgz，均为标准库原生实现、无密码。
