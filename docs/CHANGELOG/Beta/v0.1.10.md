# v0.1.10

日期：2026-11-27

## 修复

- **返回手势彻底失效（真机复现）**：根因是 OpenFic 前端注册了 Service Worker（`sw.js`，cache-first 策略），首次启动把 `/ofone-bridge.js`、`/ofone-notify.js` 缓存进 `openfic-shell-v1`，此后磁盘/服务端文件更新也不会到达页面，0.1.9 的返回手势与通知修复从未生效。现在 `ofone_patch.py` 为脚本 URL 追加内容哈希 `?v=<md5>`，内容一变 URL 即变、自然绕过 SW 缓存；`RuntimeManager` 的注入标记也改为按脚本内容 CRC32 判定，脚本变化即触发重新注入。返回逻辑改为先调用前端 `window.__ofoneBack()` 消费一次返回（子页面→关闭对话框→`history.back()` 逐级），失败再回落原生 `spaDepth`/`canGoBack`，最后才回到后台。真机验证：设置详情页→设置列表→关闭→首页，逐级正确，不再一键退回桌面。

- **系统通知开关无法开启**：同为 SW 旧缓存导致页面加载到旧版 `ofone-notify.js`（缺 `getNotificationPermission`）。修复缓存后，通知权限读取正确，主开关及四个分类开关均可正常切换为开启；「发送测试通知」可正常弹出系统通知（`pkg=cc.openfic.one`，标题「OpenFic 测试通知」）。

## 说明
