# v0.1.17（2026-11-28）

## 修复
- 编辑器内打开 AI 助手后，在任务详情页按硬件返回：此前误退到首页；现正确收起 AI 面板回到编辑页（不再触发 `history.back` 退栈）。
- 关闭 AI 面板后再次点击 AI 助手入口：现自动恢复到刚才打开的任务详情（此前仅整页刷新才会恢复，in-page 重开只显示任务列表）。

## 说明
- 通过注入脚本记录当前任务标题（`window.__ofoneLastAiTask`），按返回收起面板时置待恢复标志；再次点击编辑器内的 Agent 入口时，在右侧栏列表渲染后自动点回上次任务卡片。
- 内置 embedding/rerank 模型仍为 fastembed 首次使用懒下载；中文界面优先 `hf-mirror.com`、英文优先 `huggingface.co`（0.1.16 起）。
