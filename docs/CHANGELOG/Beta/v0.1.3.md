# Changelog

## [0.1.3] - 2026-11-27

### Changed

- 镜像选择面板的「界面语言 / Language」独占一行，语言按钮另起一行排列。\
  The "界面语言 / Language" label in the mirror panel now occupies its own line, with the language buttons on a new line.

### Fixed

- 控制台阶段 OpenFic 尚未启动，语言切换改为直接写入 `openfic.db` 的 `settings` 表，服务运行后再走设置接口，界面语言不再出现同步失败。\
  OpenFic is not running while the console is shown, so language switches now write the `settings` table in `openfic.db` directly and only use the settings API once the service is up, so the UI language no longer fails to sync.
