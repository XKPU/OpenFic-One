# v0.1.9

日期：2026-11-27

## 修复

- **返回手势适配**：Android 10+ 的全屏手势返回不再走 `onKeyDown`，之前只截获硬件按键导致手势无效。现把返回逻辑收敛到 `handleBack()`，同时实现 `onBackPressed()`，硬件键与手势都按「多级页面逐层后退 → 首页回到后台」处理。
- **系统通知不可用**：OpenFic 前端在 WebView 内检测不到 `window.Notification`，一直提示「当前环境不支持系统通知」。新增 `ofone-notify.js` 兼容层，向 WebView 注入 `Notification`（`permission`、`requestPermission`、构造函数），实际通知由原生 `NotificationManager` 发出，并适配 Android 13+ `POST_NOTIFICATIONS` 运行时授权。

## 改进

- **版本号以实际安装包为准**：`installedVersion()` 改为优先读取 `site-packages` 下 `openfic-*.dist-info` 的真实版本，再回写 `.ok`，避免因记录文件与实际安装不一致而误报版本。

## 说明

- 「One 设置」改为在原生设置对话框内进入独立子页面（上一版已改），与其它设置菜单一致，不再叠加模态窗。
