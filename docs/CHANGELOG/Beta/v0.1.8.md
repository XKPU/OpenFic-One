# Changelog

## [0.1.8] - 2026-11-27

### Added

- 更新源按界面语言排序：中文界面优先国内镜像（清华/中科大/阿里云），英文界面优先官方源（PyPI / GitHub Releases）。OpenFic 的 PyPI 镜像与 OpenFic One 的更新 API 均按此规则。\
  Update sources are now ordered by UI language: Chinese prefers domestic mirrors (Tsinghua / USTC / Aliyun), English prefers official sources (PyPI / GitHub Releases). This applies to OpenFic's PyPI mirrors and OpenFic One's update APIs.

### Fixed

- 加固根文件系统的删除/复制逻辑，不再跟随镜像根目录里指向绝对目标的软链（如 `/usr/bin/...`）：`deleteTree` 遇软链只删链接本身，`copyTree` 跳过软链，避免误删或误拷宿主目录。\
  Hardened rootfs delete/copy so they no longer follow symlinks that point at absolute host targets (e.g. `/usr/bin/...`): `deleteTree` removes only the link itself, and `copyTree` skips symlinks, preventing accidental deletion or copying of host directories.
- 「发现新版本」对话框文案更新为「通过 pip 原地升级，保留现有环境」。\
  The "new version available" dialog now says "upgrades in place via pip, keeping the existing environment".
