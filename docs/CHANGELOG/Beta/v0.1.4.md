# Changelog

## [0.1.4] - 2026-11-27

### Changed

- 控制台界面语言改为跟随 OpenFic：在 OpenFic 设置里切换语言后，控制台标题、按钮与日志文案会自动同步，无需再手动选择。\
  The console UI language now follows OpenFic: switching the language in OpenFic's settings updates the console title, buttons and log text automatically, with no manual selection needed.
- 包名由 `cc.oenfic.one` 更正为 `cc.openfic.one`，旧版本需卸载后重新安装。\
  The package name is corrected from `cc.oenfic.one` to `cc.openfic.one`; the old build must be uninstalled before installing this one.

### Removed

- 移除「手动选择语言后不再跟随服务端」的旧限制。\
  Removed the old restriction that stopped following the server after a manual language pick.
