# 安全政策

项目的一般说明见 [README.md](../README.md)，缺陷报告渠道见 [SUPPORT.md](SUPPORT.md)。

## 支持的版本

| 版本 | 支持状态 |
| --- | --- |
| 最新版本 | :white_check_mark: |
| 任意旧版本 | :x: |

安全更新仅进入最新版本，不回溯到旧版本。

安全更新通常与常规功能更新一并发版。

## 报告漏洞

**请勿通过公开 Issue 报告安全漏洞。**

请通过以下任一渠道私下报告：

- GitHub 私密漏洞报告：[https://github.com/XKPU/OpenFic-One/security/advisories/new](https://github.com/XKPU/OpenFic-One/security/advisories/new)
- 邮箱：`csaxongmail@gmail.com` 或 `u-eptm@u-eptm.top`

### 注意事项

- 我们只接收 OpenFic One 相关的安全问题，任何 OpenFic 相关的安全问题请直接向 OpenFic 项目报告。

### 请在报告中包含

1. **受影响的版本** —— 形如 `v1.0.0` 的启动器版本号，以及「One 设置」中显示的 OpenFic 版本。
2. **问题描述**及其影响。
3. **复现步骤**（如适用）。
4. **可能的修复方案**（如有）。

### 我们的响应流程

- **确认收到** —— 通常在 7 天内答复。
- **评估与修复** —— 确认问题后，在私下处理的同时准备修复。
- **公开披露** —— 修复发布后通过 GitHub 安全公告公开，并注明报告者（除非你希望匿名）。

在修复发布前，请勿公开披露问题。
